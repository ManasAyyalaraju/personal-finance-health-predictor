# Project Structure and Purpose

## Project Overview

The **Personal Finance Health Predictor** is a machine learning-powered system designed to assess credit risk, detect fraudulent transactions, and segment customers for financial institutions. The project uses multiple datasets and various ML algorithms to provide actionable insights for financial decision-making.

## Purpose

This project addresses three critical financial use cases:

1. **Credit Risk Assessment**: Predicts the likelihood of loan default to help lenders make informed approval decisions
2. **Fraud Detection**: Identifies potentially fraudulent credit card transactions in real-time
3. **Customer Segmentation**: Groups customers into behavioral segments for targeted marketing and product recommendations

## Key Components

### Data Pipeline
- **Raw Data**: Three main datasets (Lending Club, Credit Card Fraud, German Credit)
- **Preprocessing**: Feature engineering, handling missing values, encoding categorical variables
- **Processed Data**: Clean, standardized datasets ready for model training

### Model Training
- **Credit Risk**: Multiple algorithms (Logistic Regression, Random Forest, XGBoost, LightGBM)
- **Fraud Detection**: Isolation Forest and XGBoost with SMOTE for class imbalance
- **Customer Segmentation**: K-Means, Hierarchical Clustering, DBSCAN

### Deployment
- **FastAPI REST API**: Production-ready API endpoints for predictions
- **Model Serving**: Singleton pattern for efficient model loading and caching
- **Feature Preprocessing**: Replicates training-time preprocessing for inference

## Workflow

1. **Data Exploration** → Understand datasets, distributions, and relationships
2. **Data Preprocessing** → Clean, transform, and engineer features
3. **Model Training** → Train and compare multiple algorithms
4. **Model Evaluation** → Comprehensive performance analysis
5. **Customer Segmentation** → Unsupervised learning for customer groups
6. **Deployment** → API endpoints for real-time predictions

## Technologies Used

- **Python**: Core programming language

- **XGBoost/LightGBM**: Gradient boosting frameworks
